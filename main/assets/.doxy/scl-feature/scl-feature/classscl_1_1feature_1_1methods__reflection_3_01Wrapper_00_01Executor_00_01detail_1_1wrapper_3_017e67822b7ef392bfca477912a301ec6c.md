## Detailed Description


Matches `detail::wrapper<QualifiedInner_`, OuterExecutor\_&gt; when `QualifiedInner_` is a cv/ref-qualified wrapper type, and forwards to the unqualified specialization. This collapses all 12 cv/ref variants into one rule so that qualifiers on the stored type do not produce a separate, incompatible reflection chain.
