## Detailed Description


Инструмент для формирования экземпляра значения "по месту" и реализации механизма Strong [**Typedef**](structScL_1_1Feature_1_1Inplace_1_1Typedef.md). Определение "по месту" означает, что для значения не используется динамическое размещение в "куче и оно является неотъемлемой частью области видимости, в котором этот экземпляр значения определен.
