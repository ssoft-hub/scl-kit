## Detailed Description


`scl::wrapper_cast()` returns a `wrapper_caster<Refer>` proxy that captures references to every executor in the wrapper chain without acquiring any guard. Guards are activated **lazily**, only at the moment the proxy is converted to the desired target type.


This allows generic code to cast uniformly through wrapper chains: non-wrapper types are passed through as-is via a no-op overload.
