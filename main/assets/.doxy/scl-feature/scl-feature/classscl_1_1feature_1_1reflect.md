## Detailed Description


Serves as the empty base case of the `reflect` inheritance chain. `detail::wrapper` inherits (transitively) from this class; each partial specialisation for a concrete `Type` injects the proxy members generated by `SCL_REFLECT_METHOD` into the wrapper's public interface.


When `Type` matches no partial specialisation, this empty body is used — meaning no extra proxy members are added for that type.




**Template parameters:**


* `Wrapper` The outermost wrapper type that inherits this mixin. Used by `SCL_REFLECT_TYPE` to locate the executor at call time via `scl::feature::executor_trait <Wrapper>`. 
* `Executor` The outermost executor instantiation (`Executor<Wrapper::value_type>`). Exposed as `S_c_L_executor_type_` inside generated proxy methods. 
* `Type` The type whose reflected members are mixed in. Partial specialisations handle `detail::wrapper` layers (delegating to the inner value type) and concrete value types (injecting proxy members).
