# Сборка в Visual Studio

Требования и модель пресетов: [presets-intro.md](presets-intro.md).

Visual Studio 2022 (v17) и 2026 (v18) читают `CMakePresets.json` нативно при
открытии репозитория как папки — `.sln` не нужен.

## 1. Открыть папку

**File → Open → Folder…** и выберите корень репозитория. Visual Studio разберёт
`CMakePresets.json` и покажет доступные пресеты в выпадающем списке конфигураций
на панели инструментов.

## 2. Выбрать поколение под вашу версию VS

Пресеты `msvc` идут в двух вариантах, по одному на поколение VS:

- Visual Studio **2022** → `msvc-x64-2022`, `msvc-x86-2022`, `msvc-arm64-2022`
- Visual Studio **2026** → `msvc-x64-2026`, `msvc-x86-2026`, `msvc-arm64-2026`

Выбирайте вариант под версию VS, в которой открыли папку; выбор пресета 2026 в
VS 2022 (и наоборот) упадёт, потому что генератор (`Visual Studio 17 2022` против
`Visual Studio 18 2026`) не совпадёт с установленным тулсетом.

## 3. Конфигурация, сборка, тесты

- Выбор пресета в выпадающем списке конфигурирует его в `build/<preset>/`.
- **Build → Build All** (`Ctrl+Shift+B`) собирает.
- **Test → Test Explorer** обнаруживает и запускает CTest-цели.

## Подводные камни

- `msvc-arm64-*` кросс-компилируется на x64-хосте — собирается, но ARM64-бинарники
  запускаются (и тестируются) только на реальной ARM64-машине.
- `msvc-x86-*` не требует особого окружения внутри Visual Studio (генератор
  выбирает 32-битный тулсет через `architecture` пресета), в отличие от пресета
  `clang-x86` — см. [Подводные камни во введении](presets-intro.md#подводные-камни).
- Генератор Visual Studio не выдаёт `compile_commands.json`; это ожидаемо и здесь
  безвредно.
