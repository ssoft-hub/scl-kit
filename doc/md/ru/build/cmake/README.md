# Сборка и настройка — CMake-пресеты по IDE

Пошаговые руководства по сборке, тестированию и запуску ScL Toolkit из каждой
поддерживаемой IDE (и из командной строки) с использованием поставляемых
CMake-пресетов.

Начните с общего введения, затем перейдите к своей IDE:

| Руководство | Что охватывает |
|-------------|----------------|
| [Введение в пресеты](presets-intro.md) | Модель пресетов, требования по тулчейнам, сквозные подводные камни. **Прочтите первым.** |
| [Qt Creator](qt-creator.md) | Импорт пресетов по китам; правка компилятора/отладчика по умолчанию; кэш `.user`. |
| [VS Code](vs-code.md) | Расширение CMake Tools; выбор configure/build/test пресетов; выбор конфигурации. |
| [Visual Studio](visual-studio.md) | CMake через open-folder; выбор пресета `-2022`/`-2026` под версию VS. |
| [CLion](clion.md) | Соответствие пресет → профиль; подбор тулчейнов. |
| [Командная строка](cli.md) | `cmake --preset` и обёртки `script/ci/`. |

Авторитетная таблица пресетов (имя → хост → дерево сборки → примечания) —
в [CONTRIBUTING.md](../../../../../CONTRIBUTING.md#presets).
