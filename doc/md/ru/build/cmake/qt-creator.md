# Сборка в Qt Creator

Требования и модель пресетов: [presets-intro.md](presets-intro.md).

Qt Creator читает `CMakePresets.json` напрямую — каждый configure-пресет
становится конфигурацией сборки, которую можно выбрать по киту.

## 1. Открыть проект

**File → Open File or Project…** и выберите верхнеуровневый `CMakeLists.txt`
репозитория. Qt Creator обнаружит `CMakePresets.json` и предложит пресеты,
которые может исполнить ваш хост, на шаге **Configure Project**.

## 2. Выбрать пресеты

На экране **Configure Project** отметьте нужные пресеты (например,
`msvc-x64-2026`, `clang-x64`). Каждый становится конфигурацией сборки в
**Projects → Build & Run**. Переключайтесь между ними через селектор кита
(слева внизу) или страницу **Build Settings**.

## 3. Конфигурация, сборка, тесты

- **Build → Run CMake** конфигурирует выбранный пресет в `build/<preset>/`.
- **Build → Build Project** (`Ctrl+B`) собирает.
- Тесты: **Tools → Tests** (Autotests) обнаруживает CTest-цели; запускайте их из
  панели **Test Results** или добавьте шаг запуска **CTest**.

## Подводные камни

- **Пресеты импортируются с тулчейном по умолчанию, а не тем, что в пресете.**
  После загрузки Qt Creator назначает *свой дефолтный компилятор и отладчик*
  каждому импортированному пресету/киту — он **не** выводит их из пресета.
  Откройте **Projects → Build & Run → (кит) → Manage Kits…** (или CMake-настройки
  кита) и вручную поправьте компилятор и отладчик для каждого пресета: наведите
  `msvc-*-2022` на тулчейн VS 2022, `msvc-*-2026` — на VS 2026, `clang-*` — на
  Clang и т.д. Пропустив это, вы молча соберёте все пресеты одним дефолтным
  компилятором.
- **Устаревшие аргументы шага сборки.** Qt Creator запекает конфигурацию сборки
  (включая CMake/native-аргументы сборки) в `.qtcreator/CMakeLists.txt.user`.
  Если настройки сборки пресета изменились после первого импорта, перезапустите
  **Run CMake** или переимпортируйте пресеты — иначе закэшированное значение в
  `.user` победит. Если шаг сборки всё ещё показывает устаревший аргумент,
  очистите его в **Build Settings** или удалите `.qtcreator/CMakeLists.txt.user`
  (при закрытом Qt Creator), чтобы он пересоздался.
- Windows `clang-x86` и MinGW `gcc` по-прежнему требуют правильного окружения в
  `PATH` — см. [Подводные камни во введении](presets-intro.md#подводные-камни).
